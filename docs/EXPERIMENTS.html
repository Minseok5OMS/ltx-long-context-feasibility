실험별 질문과 얻은 근거

갤러리 · 처음

120회는 완료한 정식 생성 실행 수입니다. 서로 독립인 120개 사례나 120개 통계 표본이 아닙니다. 비교에 재사용한 31개 표시는 해당 원실행으로 연결됩니다. 초기 두 인터뷰는 같은 원본입니다.

1. Local smoke — 1회

요리 영상에서 Local 2초를 고정 조건으로 다음 3초를 생성했습니다. 실행·조건 주입·디코딩·평가용 Target 분리를 점검했습니다. 원본 Local과 생성 Target을 이어 붙인 5초 보기는 연결 상태 확인용입니다. 과거 증거 효용을 검증한 실험은 아닙니다.

2. 초기 참조 비교 — 신규 9회

두 인터뷰 구간에서 Local / Random / Oracle의 Video-Past를 비교하고, 첫 인터뷰의 Image-Target-guide 3조건을 추가했습니다. Random은 같은 원본의 무관한 장면을 수동 선정한 대조이며 무작위 표본 추출이 아닙니다.

Video-Past에서는 필요한 인터뷰 외관 활용에 실패한 반면 Image-Target-guide는 활용했습니다. 이 비교는 참조 형식과 시간 위치를 동시에 바꿔 원인을 분리하지 못했습니다. Target-guide는 과거 이미지의 참조 좌표를 생성 시작으로 옮긴 것이며 GT 입력이 아닙니다.

3. 이미지/영상 × Past/Target — 신규 10회, 비교 12개

같은 입력과 초기/step noise를 통제하고 seed 42/43/44에서 2×2를 비교했습니다. 기존 seed 42의 Image-Target과 Video-Past를 재사용했습니다. Image-Past도 외관을 전달하고 Video-Target도 작동했으며 Video-Past는 실패했습니다.

시간 위치 하나만으로 설명할 수 없다는 근거입니다. 세 seed에서 비슷한 경향을 보았다는 관찰을 seed가 언제나 중요하지 않다는 결론으로 확대하지 않습니다.

4. 동일 이미지 반복과 시간 배치 — 신규 3회, 비교 5개

조건 참조 내용 시간 배치 신규 여부
A 이미지 latent 1회 같은 Past 위치 재사용
B 동일 이미지 latent 10회 모두 같은 Past 위치 신규
C 동일 이미지 latent 10회 영상처럼 시간에 배치 신규
D 실제 영상 latent 시간 좌표를 같은 위치로 모음 신규
E 실제 영상 latent 원래 영상 시간 배치 재사용

A→B만으로 외관 전달이 깨졌습니다. 영상 VAE 내용이나 시간 분산이 실패의 필요조건은 아니었습니다. 반복 token 영향은 있지만 attention 질량이나 희석을 계측한 결과는 아닙니다. Video-Target의 성공도 있으므로 “많은 token은 항상 실패”라고 해석하지 않습니다.

5. 반복수 — 신규 2회, 비교 4개

동일 이미지와 같은 Past 좌표에서 1·2·4회는 외관 전달, 10회는 공사 장면 지속이 관찰됐습니다. 1회와 10회를 재사용하고 2회·4회만 새로 생성했습니다. 5–9회를 실행하지 않아 정확한 실패 임계점은 미확인입니다.

6. 서로 다른 원본 5개 — 신규 10회

관리자·로봇·학생·차량·보존 작업자를 Local-only / Local+Image-Past로 비교했습니다. 두 인물에서는 외관 전달과 참조 구도 영향이 나타났고 로봇·학생·차량은 필요한 시점 전환에 실패했습니다. 후자는 외관이 틀렸다는 판정보다 필요한 부분이 보이지 않는 실패입니다.

초기 시도에서 denoising 뒤 CUDA decoder 오류가 있어 decoder를 별도 새 프로세스로 분리했습니다. 최종 10조건을 같은 방식으로 재실행했고 실패 시도는 원작업 공간에 보존했습니다. 같은 Local 재디코딩과 재실행 6조건 latent가 정확히 일치함을 확인했습니다. 실패 시도를 정식 120회에 추가하지 않습니다.

7. 5개 전체의 2×2 — 신규 15회, 비교 25개

기존 Local과 Image-Past 10개에 Image-Target / Video-Past / Video-Target 15개를 추가했습니다. Target 배치는 로봇·학생·차량의 필요한 외관 노출을 회복했지만 참조의 구도·동작·컷·자막까지 재현하는 경향이 남았습니다. 관리자·보존 작업자는 Video-Past에서도 활용했습니다.

사용자는 전체 과거 장면을 Target 좌표로 옮기는 것을 기본 경로에서 제외했습니다. IC-LoRA는 검토했으나 장착하지 않았습니다. 피사체 추출·배경 제거·Ingredients 시트 전처리도 기본 경로로 선택하지 않았습니다.

8. Prompt 제어 — 신규 45회, 비교 60개

기존 P0에 P1(출력 구도·행동 명시), P2(P1+연속성), P3(P2+참조 역할)를 추가했습니다. 5사례 × Local / Image-Past / Video-Past × 3개 추가 prompt = 신규 45회입니다. 각 비교의 prompt를 Local과 참조 조건에 동일하게 적용했습니다. 모든 참조는 전체 프레임의 Past 입력입니다.

로봇·보존 작업자에서 참조 외관과 새 구도 결합을 관찰했습니다. 차량 Video-Past P2/P3는 외부로 전환했지만 주행 성공은 불확실합니다. 학생은 계속 실패했고 관리자 Video-Past는 P0에서 성공했던 전환이 추가 prompt에서 노트북 장면 유지로 악화됐습니다. P3가 P2보다 일관되게 낫지는 않습니다.

9. 연속 과거 32초와 선택 chunk — 신규 25회

같은 32초 안에 유용한 증거가 있는 5사례를 생성 전에 재검토·동결했습니다. Local / Native-Full / Full-reference / Oracle-sparse / Uniform-sparse를 비교했습니다. 직원·로봇의 Target 시점은 앞선 실험과 달라졌고 나머지 3개는 Oracle 구간을 바꿨습니다. 앞 실험과 단일 변수 비교로 취급하지 않습니다.

필요한 증거 선택의 부분적 품질 이점과 계산 절감이 확인됐습니다. 전체 결과·제한. 작은 offset·추가 seed·attention 계측을 더 실행하지 않고 Stage 1을 마무리했습니다.
