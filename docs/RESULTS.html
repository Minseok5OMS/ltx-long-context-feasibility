필요한 증거를 활용할 능력은 있으나 제어가 안정적이지 않다

Image-Past와 일부 Video-Past에서 과거 외관을 가져왔습니다. Prompt 비교의 로봇·보존 작업자, 마지막 선택 chunk 비교의 로봇은 새로운 구도와 외관을 결합했습니다. Target 위치 참조는 외관 노출을 회복하는 대신 과거 장면의 구도·동작·컷을 강하게 재현해 기본 경로에서 제외했습니다.

배경 유사성 자체는 실패가 아닙니다. 현재 요청을 막는 과거 행동·구도의 재현을 제어 실패로 구분합니다. 필요한 얼굴이 화면에 나오지 않으면 잘못된 identity 생성이라고 단정하지 않습니다.

Oracle 대비 Native/Full의 사례별 denoising 비율 중앙값은 4.663× / 4.703×입니다. 전체 peak allocated 감소는 7.02% / 7.10%, baseline 이후 증가분 감소는 75.52% / 75.73%입니다. 약 35.39 GiB의 상주 baseline에는 transformer와 전송한 text/condition이 포함되어 전체 VRAM 차이를 작게 만듭니다.

VAE의 시간 8, 공간 32×32 압축도 비용 구조의 일부입니다. 32초 Native BF16 latent [1,128,97,9,16] 자체는 약 3.41 MiB입니다. 이 저장 크기는 transformer hidden/attention 메모리와 다릅니다. F/O token 비율 4.28×, attention pair 이론 비율 18.32×를 실측 VRAM이나 속도 비율로 대체하지 않습니다. 실제 SDPA kernel은 별도 확인하지 않았습니다.

로딩·검사·decoder까지 포함하면 약 1.65×, 별도 준비까지 합하면 약 1.35× / 1.37×입니다. 준비+실행은 별도 측정 합이며 cold 요청 전체 시간으로 부르지 않습니다. O도 전체 H bank 인코딩 비용을 지불했습니다. 원본 ingest 및 미구현 검색/메모리 비용은 별도입니다. Native도 전체 35초를 decode하지 않고 마지막 conditioning+Target만 decode했습니다.

학습에서는 고정 generator를 통과해 메모리에 gradient를 전달하는 비용이 추가될 수 있습니다. 현재 추론의 VRAM 감소율을 학습에 그대로 적용하지 않습니다.

지표와 표본의 한계

DINOv2 전체 프레임 유사도는 보조 지표이며 identity나 과제 성공률이 아닙니다. 직원 Oracle의 GT DINO는 0.394로 Native의 0.611보다 낮지만 필요한 직원 외관은 Oracle에서 드러납니다. 학생 Oracle에는 교사 앞면도 있어 실패 영상의 Oracle 최대 유사도가 높을 수 있습니다. 로봇의 원본 후속은 요청한 display 구도의 GT가 아니므로 생성 전에 GT DINO 제외를 동결했습니다. 인접 pixel 변화량도 주행 성공 점수가 아닙니다.

마지막 실험은 이미 성공 가능성을 살핀 5개 원본, seed 42, 32초, 단일 chunk입니다. 직원은 같은 증거가 더 가까운 시점에도 나타나고 학생 O/U는 8/9 index가 겹칩니다. 길이 scaling, attention 기전, 학습된 검색, 상태·사건·상보적 복수 증거, 독립 사람 평가는 미검증입니다. 고정 모델에서 선택 증거 경로의 가능성을 확인한 결과로 남깁니다.
