# Stage 2로 넘길 목표

[처음](../README.md)

Stage 1은 선택한 과거 증거를 frozen LTX에 전달할 때의 효용과 제어 한계를 확인하고 종료했습니다. 다음 단계는 압축 전역 메모리의 최소 설계를 확정하는 일입니다. 현재 초기 설계만 있으며 feature 추출, 메모리 구현, adapter 학습은 시작하지 않았습니다.

전역 메모리는 두 역할을 모두 유지합니다.

1. 전체 영상의 문맥·관계·사건 흐름·상태를 **직접 생성 조건**으로 제공합니다.
2. 필요한 **원본 증거 위치**를 선택해 해당 LTX VAE latent로 세부 시각 정보를 보충합니다.

검색이 잘된다는 이유만으로 메모리의 직접 생성 기여를 생략하지 않습니다. 배경·물체·사람을 사전에 분리해 정보 범위를 제한하지 않고, 요청과 Local 및 전역 문맥에 따라 필요한 정보를 선택하도록 설계합니다.

| 분리할 질문 | 후속 비교 |
|---|---|
| 메모리가 직접 생성에 도움이 되는가 | **같은 Oracle 증거를 고정**하고 메모리 조건 유무 비교 |
| 메모리가 증거 선택을 돕는가 | 메모리 직접 조건은 공통으로 두고 선택 방법 비교 |
| 두 역할이 상호 보완적인가 | Local / +memory / +evidence / +both |
| 긴 문맥에서 유효한가 | 길이·방해 구간·증거량·메모리 크기별 품질/비용 |
| 외관을 넘어 정보를 쓰는가 | 상태·사건·상보적인 여러 과거 구간 의존성 |

작은 resampler, 별도 memory cross-attention, 기존 VAE cache로 첫 tensor/gradient 연결 확인, 이후 V-JEPA2/semantic fusion, 32→60→120초 확대는 검토 중인 제안입니다. 모델 차원·메모리 token 수·encoder·학습 범위를 동결한 실행 계획으로 간주하지 않습니다.

현재 약 4.7×는 선택된 증거의 denoising 비용 이점입니다. 학습된 memory 구축과 검색 비용을 포함한 시스템 이점은 새로 측정해야 합니다. 학생·차량 행동·불필요한 장면 재현을 실패 사례로 유지하고 성공 영상만으로 후속 목표를 좁히지 않습니다.
